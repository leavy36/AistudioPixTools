# PocketPDF v3 — Description

## Tagline
Your local image toolkit — convert iPhone HEIC, resize for every social network, and Smart-Shrink your photos to email-friendly size. 100% in your browser. Zero cloud, zero cost, zero tracking.

## What's inside (3 focused modules)

### 🔁 Convert
- **HEIC → JPG/PNG** — turn any iPhone photo into a universal format
- **Universal converter** — PNG · JPG · WebP, any direction

### 🖼️ Resize (Icon & Banner)
Pre-set dimensions matching the latest 2025-2026 official specs for:
YouTube (thumbnail, banner, Shorts, profile), Instagram (post, portrait, story/reel), TikTok, X (post, header), Facebook (post, cover), LinkedIn (post, banner), Pinterest, Web/PWA icons, favicons, Open Graph.
Fit modes: cover · contain · stretch. Output PNG/JPEG/WebP/ICO.

### 🗜️ Optimize — Smart Shrink
Shrinks image weight for email, forms and messaging apps — usually **5 to 10× lighter**, visually identical.
Presets:
- Visually identical (quality 0.85, keep size)
- Email friendly (≤ 500 KB, max 1920 px)
- Messaging (≤ 200 KB, max 1600 px)
- Web / blog · Thumbnail · Custom
Auto-tunes JPEG/WebP quality (and downscales as a fallback) until it hits your target file size.

## Privacy & cost
- **0 €** running cost — no server, no API key, no subscription
- **0 byte uploaded** — files never leave your computer
- **No tracking, no analytics, no cookies**
- Small batches capped at **15 files** to stay fast and predictable

## How to run
1. Unzip `pocketpdf.zip`
2. Double-click `index.html` — that's it.
   (or install as a PWA from the hosted version)

## Tech
Vanilla HTML / CSS / JS · JSZip (batches) · heic2any (HEIC decode, loaded on demand). All processing uses the browser Canvas API.
